joins :-- will extract the data from two or more tables

inner join  :-- will return common values from both 		tables

>>>select * from table1 inner join table2 on table1.col_name=table2.col_name;


left        :--  will return all values from left table and common values from 		right table

>>>select * from table1 left join table2 on table1.col_name=table2.col_name;


right       :-- will return all values from right table and common values from 		left table

>>>select * from table1 right join table2 on table1.col_name=table2.col_name;
