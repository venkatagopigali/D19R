dml :-- data manipulation language :-- will perform operations on table data

insert   :-- will add a new record or data to table 		data
single record:
------------------------------
>>>insert into table_name values(v1,v2,v3--);

multiple records:
-------------------------------------------
>>>insert into table_name values(v1,v2,v3--),(v1,v2,v3---)----;

selected columns:
-------------------------------------------
>>>insert into table_name(col_name1,column_name2) values(v1,v2);


before perform update or delete we need disable security option:
-----------------------------------------------------------------
>>>set sql_safe_updates=0;


update   :-- will modify the existing data


>>>update table_name set column_name='new_data' where condition;

>>>update table_name set col_name=new_data,col_name2=new_data-- where condition;
