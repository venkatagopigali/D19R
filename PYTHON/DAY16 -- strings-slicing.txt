>>>it is ordered collection

>>>we can access with index and slicing 

index :-- we can access the only on letter a time 
positive(forward) --> start from --> 0 , left to right
negative(backward)--> start from --> -1, right to left
>>>we can use [] to represent in index


slicing :-- we can access the  more then one character at a time
[start:stop:step]
[start:stop]     --> step --> 1
[:stop]          -->start --> 0 ,step --> 1
[::step]          --> start --> 0 , stop -->end of string
[start:]          --> stop -->end of string , step -->1
